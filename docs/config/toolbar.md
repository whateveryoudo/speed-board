# 浮动工具栏与样式面板

SpeedBoard 采用了统一的 **Schema 驱动体系**，选区气泡栏（FloatingToolbar）与右侧样式抽屉（StyleSettingsPanel）根据当前选中图元的类型动态装配。

---

## 1. 选区浮动工具栏 (FloatingToolbar)

- **自适应视口跟踪**：当用户在画布中单选、框选图元或选中思维导图节点时，浮动工具栏计算选中包围盒的屏幕绝对坐标，紧贴图元上方自适应悬浮；
- **动态 Schema 装配**：
  - **思维导图节点**：显示同级/子级添加、布局切换、概要（Summary）归纳、优先级（P1~P7）、完成进度（0%~100%）、旗帜标记等；
  - **几何图形**：显示填充色、边框粗细与色值、文字排版、图层排序等；
  - **连线**：显示连线类型（正交/直线/平滑曲线）、端点箭头样式（实心/空心/圆点/菱形等）、线宽与颜色；
  - **多选状态**：自动显示多图元对齐与等间距分布快捷操作。

---

## 2. 深度右侧样式抽屉 (StyleSettingsPanel)

右侧面板提供深度属性配置，分为三大 Tab：

1. **样式 Tab**：
   - 填充颜色、透明度滑块；
   - 边框线型（实线/虚线）、边框粗细、圆角半径；
   - 连线样式与箭头端点类型。
2. **文本 Tab**：
   - 字号大小、文字颜色、加粗、斜体、下划线、删除线；
   - 文本水平对齐（左、中、右）与行高。
3. **排列 Tab**：
   - 多图元几何对齐（左对齐、居中对齐、右对齐、顶对齐等）；
   - 水平/垂直等间距分布；
   - 图层层叠层级与成组（Group）/解组。
