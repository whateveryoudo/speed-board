# 介绍

**SpeedBoard** 是一套基于纯原生 SVG 白板引擎 **Plait** 打造的现代协同白板与思维导图套件。

针对业务系统开发中对“白板”与“思维导图”不同形态的使用诉求，SpeedBoard 提供了清晰解耦的双场景组件：
1. **`<SpeedBoard />`**：全功能协作白板，适合无界画布、自由草稿、业务流程图与头脑风暴，支持同时排版多棵导图、几何图元、连线与手绘；
2. **`<SpeedMindmap />`**：独立思维导图专属文档，画布中央默认渲染单一根节点，开箱即写，屏蔽白板左侧工具栏与落点门槛，专注于深度树形思考。

## 来源、生态与核心差异

### 致敬与借鉴
本项目在底层核心能力上借鉴并参考了优秀开源项目：
- [worktile/plait](https://github.com/worktile/plait)：提供坚实的原生 SVG 白板底层架构模型与渲染插件流水线；
- [plait-board/drawnix](https://github.com/plait-board/drawnix)：开箱即用的白板应用参考实现。

如果你之前了解或使用过 Plait 或 Drawnix，可以把 **SpeedBoard** 理解为面向 **Vue 3 生态**的现代化封装与深度业务定制实现。

### 沿用的官方核心包
为了保持架构的纯粹与轻量，本仓库仅沿用了 Plait 最核心的基座包：
- `@plait/core` 与 `@plait/common`：视口变换、指针事件分发、基础插件链机制与几何计算；
- `@plait/layouts`：基础树状排版布局计算；
- `@plait/text-plugins`：富文本协议规范与 Slate 基础支持。

### 核心差异与自研优化

1. **思维导图（Mindmap）全链路自主实现**：
   - 官方原生 mind 模块定制难度较高、对复杂业务场景的扩展受限；
   - 本仓库对思维导图进行了全新独立实现，完全解耦了排版、主题与交互；
   - **新增自由连线支持**：思维导图节点具备与普通几何形状图元完全一致的连接能力，支持从任意脑图节点向外拖拽端点建立正交避障折线或平滑曲线，实现脑图与白板图形间的任意互联。

2. **文本渲染「查看态 / 编辑态分离」极致性能优化**：
   - 官方原版实现中，画布内所有包含文字的节点都会常驻创建并挂载一个独立的 Slate 编辑器实例。在多图元或大型思维导图场景下，庞大的 DOM 节点数与监听开销会导致视口平移与缩放发生卡顿（参考官方 Issue [#564](https://github.com/worktile/plait/issues/564)）；
   - SpeedBoard 采用了**查看态 / 编辑态分离模式**：
     - **非编辑态**：以轻量静态矢量/纯文本形式高效呈现，内存占用与 DOM 节点数极低；
     - **编辑态**：仅在用户双击或激活特定节点时，才按需挂载 Slate 实例进行原位排版，失焦后立即销毁并同步静态数据。这使得在拥有成百上千节点的复杂白板中，依旧能保持丝滑的 60 FPS 漫游帧率。

## 核心特性一览

| 模块 | 核心能力 |
| :--- | :--- |
| **思维导图引擎** | 11 种结构布局（逻辑图向左/向右/双向、组织架构、鱼骨图、时间线等）；优先级/进度/旗帜标记；概要（Summary）大括号分组；极简键盘流（Tab 增加子级、Enter 增加同级） |
| **基础几何图元** | 19+ 种标准矢量图元（矩形、椭圆、菱形、立方体、气泡等）；原生 Slate 富文本双击排版；中空穿透点击优化（`withHitEnhance`） |
| **智能连线路由** | 内置曼哈顿正交避障算法（Manhattan Router）；移动图形时折线 90° 直角绕行；9 种端点箭头形态；端点磁吸联动 |
| **手绘画笔** | 平滑 Catmull-Rom 贝塞尔曲线拟合；多挡粗细与调色盘 |
| **1:1 原生待放置虚影** | 原生绝对坐标渲染 `PlacementGhostOverlay`，杜绝缩放模糊与落地抖动 |
| **Schema 驱动体系** | 选区浮动工具栏与右侧样式抽屉由选中目标图元 Schema 动态装配；支持对齐、等间距分布、图层层叠与成组 |
