# 11 种布局与节点标记

SpeedBoard 的思维导图引擎基于树状布局算法，支持多达 11 种结构布局以及丰富的节点标记系统。

---

## 1. 结构布局类型

可以在选区浮动工具栏或节点属性中随时切换结构形态：

| 布局标识 | 中文名称 | 适用场景 |
| :--- | :--- | :--- |
| `right` | 逻辑图（单向向右） | 最常用的思维导图，层级清晰 |
| `left` | 逻辑图（单向向左） | 对称排版或特定逆向推导 |
| `standard` | 逻辑图（左右平衡分布） | 头脑风暴与发散性思考 |
| `organization` | 组织架构图 | 企业汇报层级、部门职责结构 |
| `downward-org` | 自顶向下架构图 | 技术分层架构、系统模块展开 |
| `fishbone` | 鱼骨图（因果分析） | 根本原因分析（5M1E）、质量工程分析 |
| `timeline` | 时间线结构 | 业务里程碑、产品发版规划、历史节点 |
| `indent` | 缩进大纲图 | 代码大纲、文档结构树、目录层级 |
| `tree-up` | 向上发散树 | 向上汇报与汇聚型逻辑 |
| `horizontal-tree` | 水平发散树 | 水平流转结构 |
| `compact` | 紧凑型网格导图 | 大量密集体量节点的极简排布 |

---

## 2. 节点形态与连线风格

- **卡片形态**：
  - 圆角卡片（Round Card）
  - 胶囊卡片（Pill Capsule）
  - 纯文本下划线风格（Underline Style）
- **连线形态**：
  - 平滑贝塞尔曲线（Smooth Curve）
  - 直角折线（Right Angle）

---

## 3. 标记与概要（Summary）

- **优先级标记**：支持就地切换 `P1` 到 `P7` 优先级彩色圆标；
- **进度标记**：支持 `0%`、`25%`、`50%`、`75%`、`100%` 扇形进度指示；
- **旗帜与状态**：支持多种颜色旗帜与完成打勾状态；
- **大括号概要（Summary）**：
  选中同级的多个兄弟节点后，一键生成大括号概要分支，用于对一组子主题进行总结归纳，并支持在概要节点后继续无限扩展子分支。
